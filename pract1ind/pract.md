# Индивидуальное задание, вариант 19

Выполнены первые три этапа. [Документация и примеры](README.md).

## Этап 1. REPL

- Консольный интерфейс с приглашением `username@hostname:~$ `.
- Реальные имя пользователя и имя хоста берутся из ОС.
- Парсер раскрывает `$NAME` и `${NAME}` из окружения реальной ОС.
- Команды-заглушки `ls` и `cd` выводят своё имя и аргументы.
- `exit` завершает приложение.
- Ошибки команд, аргументов и синтаксиса показываются пользователю.
- Интерактивная проверка выполнена в терминале; последовательность
  команд для повторения приведена в README.

Пример проверенного вывода:

```text
boyjayy@MacBook-Pro:~$ ls -al "$HOME"
ls: аргументы = ["-al", "/Users/boyjayy"]
boyjayy@MacBook-Pro:~$ ls '$HOME'
ls: аргументы = ["$HOME"]
boyjayy@MacBook-Pro:~$ unknown
Ошибка: неизвестная команда: unknown
boyjayy@MacBook-Pro:~$ cd first second
Ошибка: cd принимает не более одного пути
boyjayy@MacBook-Pro:~$ exit
```

## Этап 2. Конфигурация

- Параметры `--vfs`, `--prompt`, `--startup-script`.
- При запуске выводятся все настройки.
- Стартовый скрипт исполняется последовательно; ошибочные строки
  пропускаются с сообщением, содержащим номер строки.
- Ввод и вывод скрипта отображаются как диалог с пользователем.
- Ошибки чтения скрипта обрабатываются.
- Подготовлены два скрипта ОС для проверки всех параметров.

Запуск из папки `pract1ind`:

```sh
sh run.sh
sh scripts/demo_success.sh
sh scripts/demo_errors.sh
python3 -m unittest discover -s tests -v
```

## Этап 3. VFS

- Источник VFS - директория, указанная через `--vfs`.
- Структура каталогов и байты файлов полностью загружаются в словарь
  в памяти; источник не изменяется. Без параметра создаётся пустая VFS.
- Виртуальный корень `/` соответствует корню исходной директории.
- Поддержаны вложенные и пустые каталоги, текстовые и двоичные файлы,
  скрытые файлы и русские имена с пробелами.
- Служебная команда `vfs-info [путь]` показывает сведения из памяти.
- Ошибки источника, чтения и неподдерживаемых типов файлов обрабатываются.
  Символические ссылки отклоняются.
- Два скрипта ОС проверяют минимальную VFS, несколько файлов и три уровня
  вложенных каталогов. Единый стартовый скрипт показывает все команды
  этапов 1-3 и продолжение после ошибок.
- Тесты проверяют независимость снимка от исходных файлов и отсутствие
  обращений к диску при выполнении операций с VFS.

Демонстрация из папки `pract1ind`:

```sh
sh scripts/demo_vfs.sh
sh scripts/demo_vfs_errors.sh
```

Для самостоятельного просмотра:

```sh
sh run.sh --vfs examples/vfs/deep
```

Затем ввести `vfs-info`, `vfs-info /level1/level2/level3/data.txt`, `exit`.

Полноценная логика `ls` и `cd` относится к этапу 4; пока это заглушки.
