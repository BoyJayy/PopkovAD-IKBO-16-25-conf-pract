# Практическая работа № 2. Вариант 19

Консольный визуализатор зависимостей пакетов Ubuntu на Python 3.10+.
На этапе 1 программа читает конфигурацию и печатает её в формате
`ключ: значение`. Сборка и установка Python-библиотек не требуются.

```sh
sh Prog2/run.sh Prog2/examples/mawk.yaml
python3 -m unittest discover -s Prog2/tests -v
```

| Ключ | Значение |
| --- | --- |
| `package` | Имя пакета APT или имя из заглавных латинских букв в тестовом режиме. |
| `repository` | HTTP(S) URL индекса или путь к тестовому файлу относительно YAML. |
| `test_mode` | `true` для локального файла, `false` для Ubuntu. |
| `version` | Точная версия пакета, строка в кавычках. |
| `ascii_tree` | `true` включает вывод ASCII-дерева. |
| `exclude` | Подстрока имени исключаемых пакетов. `""` отключает фильтр. |

Поддерживается плоский YAML из шести обязательных ключей в UTF-8. Один
параметр на строку, без отступов. Допустимы комментарии и строковые значения
без кавычек или в одинарных/двойных кавычках. Пишите логические значения без
кавычек. Дубликаты и лишние ключи считаются ошибками. Ошибка конфигурации
печатается в stderr с кодом завершения 1.

## Этап 2. Индекс Ubuntu

`repository` указывает непосредственно на бинарный индекс `Packages`,
`Packages.gz` или `Packages.xz` одного выпуска, компонента и архитектуры
Ubuntu. В примере используется Ubuntu 24.04 LTS (noble), `main`, `amd64`.
Программа скачивает индекс по HTTP(S), самостоятельно читает его записи
и выбирает пакет по точному совпадению имени и версии. Она извлекает
обязательные зависимости из `Pre-Depends` и `Depends`, сохраняя версии,
альтернативы и строки продолжения. При отсутствии версии сообщает,
какие версии нашлись в указанном индексе.
